# 个人财务管理工作台（dsh-personal-finance-workbench）

把一份 Excel / CSV 个人流水，变成一套**看得懂、拿得走**的个人财务分析：数据体检 → 口径确认 → 收支 / 结构 / 异常分析 → 可编辑的 xlsx 与一页结论 docx。

数据只在本机读取和计算，不上传任何服务器；导出物保存在本机工作台目录，随取随用。

## 能做什么

1. **数据接入**：选择文件夹或直接粘贴路径，读取 `.xlsx` / `.xlsm` / `.csv`（自动识别 UTF-8 / GB18030 编码与分隔符，自动定位表头行）。
2. **数据体检**：逐列识别类型（数值 / 日期 / 文本）、缺失率与示例值，列出需要处理的数据问题；自动跳过「合计 / 总计 / 小计」行。
3. **口径映射**：用下拉框确认「日期、金额、收支方向、分类、账户」分别对应哪一列；没有方向列时按金额正负判断。
4. **财务看板**：KPI 卡片（总收入、总支出、净结余、储蓄率、月均支出、结余趋势）+ 内联 SVG 图表（月度收入与支出分组柱、储蓄率走势折线、月度结余正负柱、支出结构环形图、收入来源环形图、异常与提示）+ 明细表；异常与提示覆盖大额单笔、分类环比波动、连续赤字月、储蓄率偏低、未分类过多、疑似转账 / 还款、重复流水、支出集中。
5. **交付文件**：一次生成两份可编辑文件——
   - `*.xlsx`：概览、月度收支、支出结构、收入来源、收支明细、数据体检、口径卡、复跑对比，全部使用**原生 Excel 公式**（打开即重算）；
   - `*.docx`：一页结论，含摘要、关键指标、月度收支、支出结构、异常与建议、口径说明。
6. **复跑对比**：同一份数据再次生成时，自动与上一次结果对比（总收入、总支出、净结余、储蓄率变化）。

## 数据要求

- 一行一笔收支，至少包含：**金额列**（必填，正数）；建议包含日期列与收支方向列。
- 没有收支方向列时：负数视为支出、正数默认视为支出（会在数据体检中提示）；全为正数时请补一列方向。
- 分类、账户列可选：没有分类列时统一归入「未分类」，没有账户列时跳过账户信息。
- 金额请用数值；带「元 / 万元」等单位的文本会按数值近似读取，正式使用前建议在源表统一单位。

## 计算口径

- 总收入 = 收入方向金额合计；总支出 = 支出方向金额合计
- 净结余 = 总收入 − 总支出
- 储蓄率 = 净结余 ÷ 总收入
- 支出结构 = 分类支出 ÷ 总支出；支出环比 = 本月支出 ÷ 上月支出 − 1

## 本机目录

默认根目录 `工作台根目录/personal-finance-workbench`（由 bundle 配置 `dshHomePath('personal-finance-workbench')` 指定）：

- `exports/`：生成的 xlsx / docx 与 `history.json`（复跑对比用）
- `samples/`：示例个人流水

## 技术结构

- `index.js`：Host 侧入口，注册 `/api/personal-finance-workbench/*` 本机接口（info / list / inspect / analyze / report / sample / reveal / download）。
- `engine/finance.py`：分析引擎，使用 DSH Desktop 自带的 office-runtime Python（openpyxl + python-docx + pandas）生成 xlsx / docx。
- `client.js`：Client 侧单文件面板，整页业务布局（customFrame），左侧步骤栏 + 主工作区，按需打开 AI 对话。
- `cordis.patch.yml`：bundle 注册与根目录配置。

## 已知限制（v0.1）

- 单文件分析；一次只读一个工作表（默认第一个有数据的表）。
- 不做多表关联与多文件合并。
- 不做资产负债、投资收益、预算与多币种换算（v0.2 规划）。
- 金额单位沿用源表，不做自动换算。
